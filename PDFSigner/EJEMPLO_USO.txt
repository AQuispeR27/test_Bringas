=============================================================================
    GUÍA RÁPIDA DE USO - FIRMA DIGITAL DE PDFS
=============================================================================

Este archivo contiene un ejemplo rápido de uso del sistema de firma digital.

PASOS RÁPIDOS:
--------------

1. GENERAR CERTIFICADO (solo la primera vez):

   cd scripts
   ./1_generar_keystore.bat    (Windows)
   ./1_generar_keystore.sh     (Linux/Mac)

   Ingresar:
   - Contraseña: miPassword123
   - CN: Juan Pérez
   - OU: Sistemas
   - O: Mi Universidad
   - L: Lima
   - ST: Lima
   - C: PE

2. COMPILAR EL PROYECTO:

   mvn clean package

3. FIRMAR UN PDF:

   java -jar target/pdf-signer.jar

   Ingresar:
   - PDF a firmar: documento.pdf
   - PDF de salida: [Enter para auto]
   - Keystore: mifirma.p12
   - Contraseña: miPassword123
   - Alias: [Enter para "mifirma"]
   - Razón: Aprobación del documento
   - Ubicación: Lima, Perú

4. VERIFICAR:

   Abrir documento_signed.pdf en Adobe Reader
   Ver panel de firmas (icono de firma en la barra lateral)

=============================================================================

COMANDOS ÚTILES:
----------------

# Ver contenido del certificado:
keytool -list -v -keystore mifirma.p12

# Exportar solo el certificado público (sin clave privada):
keytool -export -alias mifirma -file certificado.cer -keystore mifirma.p12

# Ver información de un PDF firmado:
# Abrir en Adobe Reader y revisar Panel de Firmas

NOTAS IMPORTANTES:
------------------

- El archivo mifirma.p12 contiene tu CLAVE PRIVADA
- NUNCA compartas este archivo
- Haz backup seguro de este archivo
- Si pierdes la contraseña, no podrás usarlo
- Si se compromete, genera uno nuevo inmediatamente

- El certificado es válido por 365 días
- Después de expirar, genera uno nuevo
- Las firmas antiguas siguen siendo válidas
